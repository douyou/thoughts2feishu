# 飞书权限清单

导入与打密级涉及的权限如下。以飞书开放平台控制台实际可勾选项为准；开通后必须 **创建版本并发布**。

## 应用身份（tenant_access_token）— 导入主路径

| 权限（名称可能随控制台文案变化） | 用途 |
|---|---|
| `wiki:wiki` 或等价「查看、编辑和管理知识库」 | 建节点、列子节点、移动文档入 Wiki |
| `wiki:node:create` / `wiki:node:move`（若单独列出） | 创建 / 移动节点 |
| `docs:document:import` | 创建 Word/Markdown 导入任务 |
| `docx:document`（读写） | 读写新版文档（插子页面列表等） |
| `drive:drive` 或文件上传相关 | 上传素材、导入源文件 |

探测接口：

- `POST /auth/v3/tenant_access_token/internal`
- `GET /wiki/v2/spaces/get_node`
- `POST /drive/v1/import_tasks`（需先 upload）

## 用户身份（user_access_token）— 密级

| 权限 | 用途 |
|---|---|
| `docs:secure_label` / `docs:secure_label:write_only` | 设置文档密级（L2 等） |

说明：部分租户下 **应用身份无法申请** 密级写权限，因此导入用机器人，打标用个人授权 token。

接口：

- `PATCH /drive/v2/files/:file_token/secure_label?type=docx`

## 知识库侧（非开放平台勾选，但必须做）

- 应用机器人加入目标知识库（或父节点所在空间）为 **管理员**
- 确认 `GET /wiki/v2/spaces` 能看到目标 `space_id`（看不到则应用无空间权限）

## 常见报错对照

| 现象 | 可能原因 |
|---|---|
| `docs:document:import` 相关 code 非 0 | 权限未开或未发布版本 |
| `131005 not found` / parent wiki not exist | 机器人不是该库管理员，或节点/空间已删 |
| `99991668 Invalid access token` | user token 过期 |
| 导入成功但无 L2 | 未传 user token 或密级权限不足 |
