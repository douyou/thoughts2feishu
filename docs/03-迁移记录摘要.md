# 实践经验摘要（已脱敏）

本文只记录通用结论，不含企业名称、个人账号、真实 token / Cookie / 内部文档标题。

## 曾验证过的能力

| 能力 | 结论 |
|---|---|
| Thoughts 按 folders 子树导出 docx | 可用；部分特殊节点会 `export failed`，需人工补档 |
| 飞书导入为可编辑 docx + 保留目录树 | 可用（应用身份 + 知识库管理员） |
| 同名「目录 + 正文」合成父页 | 可用；正文页不要插「子页面列表」 |
| 批量设置文档密级 | 通常需 **user_access_token**，应用身份往往无密级写权限 |
| 长时任务 | 导入用 App ID/Secret；密级导入结束后再打 |

## 常见故障

1. **并发导入** → 飞书同名重复页。始终单进程 + flock。
2. **目标知识库中途 not found** → 机器人权限被收回或空间不可见；先 `get_node` / `list spaces` 自检。
3. **user token 过期** → 仅影响密级；不影响已用应用身份导入的文档。
4. **标题含 `/`** → 导出侧需替换为全角，否则本地路径被拆坏。
